# AIDigiWorx Tech Freelancer OS

**Price target: R250**

A practical Notion-ready operating system for software developers, IT consultants, tech VAs, UI/UX designers and other tech freelancers.

- Project Pipeline / Kanban

- Financial & Invoice Log

- Quick-start guide

Import the CSV files into Notion, then apply the suggested property types and views in `Dashboard-Setup-Guide.md`.
