# Dashboard Setup Guide

Create a Notion page named **AIDigiWorx Tech Freelancer OS**.

## Client CRM
Import `01_Client_CRM.csv`.
Status: Lead, Contacted, Proposal, Active, Paused, Completed, Lost.
Priority: Low, Medium, High.
Views: All Clients, Leads, Active Clients, Follow-Ups.

## Project Pipeline
Import `02_Project_Pipeline.csv`.
Stages: Lead, Discovery, Proposal, Approved, In Progress, Review, Completed.
Create a Board view grouped by Stage.

## Task & Bug Tracker
Import `03_Task_Bug_Tracker.csv`.
Status: Backlog, To Do, In Progress, Blocked, Review, Done.
Priority: Low, Medium, High, Urgent.
Views: Board by Status, High Priority, Due This Week.

## Financial & Invoice Log
Import `04_Financial_Invoice_Log.csv`.
Status: Draft, Sent, Part Paid, Paid, Overdue, Cancelled.
Views: Outstanding, Overdue, Paid.

## Weekly workflow
Monday: review leads, projects and invoices.
Daily: update tasks and next actions.
Friday: follow up on leads and review money owed.
